01 · 菜品范式

一个范式 = 一组稳定的工序骨架 + 一组高频例外。

烧类

初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味

先出香、再加液；最后把多余水分收掉。

水煮／汆烫类

主料上浆／预处理 → 素菜焯水垫底 → 炒底汤（或煎骨冲开水成奶汤）→ 主料短时汆熟 → 装盘 → 泼热油

汤底负责主体味道，主料最后短时间成熟。

酥炸／干煸类

腌味 → 挂糊／拍粉（或直接炸）→ 初炸定型 → 复炸脱水（视菜而定）→ 回锅炒香裹味

先定型、再脱水，最后回锅赋味。

小炒类

切配 → 荤料上浆／预熟 → 滑油或煸出油 → 炒香底料与配菜 → 回锅调味或淋碗汁 → 勾芡明油

荤料先定型，回锅后快速完成味型。

面点类

发酵面：和面 → 一发 → 成型 → 二发 → 蒸；油酥／煎炸面：和面 → 制酥 → 成型 → 煎或炸

分发酵面与油酥／煎炸面两条支线。

焯灼／浇汁类

主料焯熟 → 装盘 → 另锅炒汁／调汁 → 勾薄芡 → 淋汁或蘸食

主料与味汁分开做，最后合体。

蒸扣类

预处理 → 调味／裹粉或抹馅卷制 → 码碗定形 → 长时间蒸 → 倒扣或改刀装盘

先定形再长蒸，出锅倒扣或改刀装盘。

快炒素菜／短时熟化类

洗切 → 必要时短焯（水中加盐、油保色）→ 底油爆香 → 快炒 → 起锅前调味 → 立即出锅

全程求快，保色保脆。

汤类

泡血水 → 焯水 → 炒／煸出油 → 冲入开水 → 长时间压煮（可打碎部分主料增浓）→ 最后调味

先炒后冲开水，汤色才白。

抹油／垫姜葱 → 蒸 8~10 分钟 → 状态判熟

以原料状态判断熟度，而非死记时间。

02 · 核心技法

肉类保护层

上浆

味 → 水 → 蛋（可选）→ 粉 → 油

薄层覆盖原料表面，用于鱼片、肉丝、鸡丁等；笔记强调现上浆、现炸、不等待。

适合小酥肉、糖醋里脊；重点是糊的稠度和下锅时机。

拍粉

原料表面处理 → 吉士粉/生粉等干粉附着

与挂糊不同：不是湿糊包裹，而是表面形成干粉层。香辣虾明确要求拍粉而非上浆。

下味的时间点

调味时机

加热前（腌味）→ 加热中（炒·烧）→ 加热后（拌／醋·明油·泼油修香）
  • 加热前：腌味、炸鱼等。
  • 加热中：炒、烧。
  • 加热后：拌；或最后用醋、明油、泼油修香。

油温

1 成 ≈ 30 ℃；4 成滑油 → 6 成定型炸壳 → 8 成短时复炸

  • 6 成：定型、炸壳。
  • 8 成/更高：短时复炸增脆。

烧类

红烧牛腩

01

特色 · 牛腩干煸焦壳出油；糖色；高压20分钟；分两次加西红柿

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
做法
  1. 牛腩切 2 厘米见方的麻将块、冲血水、挤干水分；西红柿去皮切块、备用。
  2. 牛腩冷水下锅，加姜片、花雕酒，撇净浮沫、加花椒，水开后煮 2~3 分钟捞出，用原汤冲洗干净。
  3. 炒糖色。
  4. 起锅烧油，牛腩干煸至焦壳出油。
  5. 炒香：葱姜蒜、干辣椒、豆瓣酱、桂皮1、八角2、香叶2。
  6. 加开水（没过牛肉），加糖色与十三香；下一半西红柿；转入高压锅，上汽后20分钟。
  7. 高压锅自然冷却，开盖。捞出香料。放入另一半西红柿，小火收汁，调味（补：生抽/盐，胡椒粉）。
  8. 葱花/蒜叶点缀，出锅。
烧类

红烧鱼块

02

特色 · 腌制时先不放淀粉；后加粉；6~7成油炸定型；整颗青椒提香；全程不翻

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
选料草鱼
做法
  1. 杀鱼：去牙齿、黑膜，用盐水洗鱼块。
  2. 腌制 10 分钟（不放淀粉）：姜、葱、料酒、盐、糖、味精。
  3. 然后去掉姜葱，加淀粉抓匀。
  4. 锅中宽油，6~7 成热下鱼块炸至定型。炸的时候不要拨动，而是转锅。
  5. 锅内留底油，煸香姜葱蒜、泡椒／辣椒、豆瓣酱 / 老干妈，加生抽炒香；加水烧开，一点醋。
  6. 放鱼块，调味（胡椒粉，耗油等），放入整颗青椒提香，加盖烧 10~12 分钟收汁（配菜在 8 分钟时加入），捞出青椒。大火收汁。
烧类

啤酒鸭

03

特色 · 鸭块去血水、焯水；豆瓣酱炒红油；鸭块微焦；啤酒+水；最后收汁

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
选料白条鸭（剁块）
做法
  1. 鸭块流水洗净血水。
  2. 冷水焯水，加姜、酒、花椒煮 2~3 分钟，用温水清洗干净。
  3. 锅底油，下豆瓣酱 2 勺炒出红油；爆香姜、蒜、干辣椒；放入鸭块，中小火煸炒 1 分钟至微焦；加八角、桂皮、香叶炒香。
  4. 加啤酒，加水没过鸭子，加糖色／老抽、十三香、胡椒粉、姜，煮开转中小火 20 分钟。
  5. 大火收汁，调味，下青椒片出锅。
烧类

可乐鸡翅

04

特色 · 打花刀腌30分钟；煎时少翻；可乐+生抽+冰糖；收至黏

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
选料鸡翅中 / 大鸡腿拆肉
做法
  1. 鸡翅打花刀，腌制 30 分钟：盐（多）、味精、姜、葱、料酒。
    ＊如果突出蒜香，可用蒜蓉挤水腌制。
  2. 冷水下锅焯水，出浮末后出锅，用温水洗净、沥干水分。
  3. 锅内放油，煎鸡翅至两面微黄（不要翻，而是动锅）。
  4. 放姜，可乐没过鸡翅，加生抽、冰糖。
  5. 大火烧 5~8 分钟，收汁至黏即可。

红烧肉

05

特色 · 硬五花；猪皮处理；煸炒持续舀油；糖色；高压12分钟/普通锅40分钟

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
选料硬五花肉（夹层五花）
做法
  1. 锅烧热，把猪皮烫焦，刮掉猪毛，洗净。
  2. 改刀切成麻将块。
  3. 冷水下锅，加料酒、姜、花椒，焯水约 2~3 分钟。
  4. 炒糖色。
  5. 锅底油，放五花肉块小火煸炒至微焦出油，不断舀出多余的油。
  6. 下八角、香叶、桂皮炒出香味，倒入热水、糖色（或：红烧酱油；黄冰糖+老抽）、料酒、姜、干辣椒、十三香。
  7. 高压锅压 12 分钟，或普通锅煮 40 分钟。
  8. 大火收汁，调味（一般补盐）。
快速版
  1. 肉去皮、焯水、切块，用酱油、香料炒匀，高压锅 12 分钟，锅里直接收汁。
烧类

土豆烧鸡

06

特色 · 鸡先焯再炒香；土豆后下；最后青红椒快速合锅

范式步骤 · 初加工（焯水／腌制）→ 煎·煸·炸定型 → 炒糖色／炒香底料 → 加热水或汤 → 焖烧入味 → 收汁调味
选料三黄鸡（嫩鸡）、黄心土豆
做法
  1. 土豆切滚刀块，泡水后捞出沥干。
